# מנהל דפי עבודה אינטראקטיביים וחיבור ל-Google Sheets

סקיל זה מנחה את הסוכן בבנייה של דפי עבודה אינטראקטיביים מתקדמים ב-HTML יחיד (Single-file HTML),
המחוברים ישירות ל-Google Sheets של המורה, כולל שער כניסה לתלמיד, מנגנון שמירה אוטומטית שקט,
ממשק ניהול שיעור מוגן סיסמה למורה, הפרדת נתונים מוחלטת בין מורות שונות, ויכולת שכפול והורדה
של קובץ תלמיד ייעודי ונקי לחלוטין.

## 1. מבנה טכנולוגי ועיצובי כללי

1. **קובץ יחיד ועצמאי:**
   - קובץ HTML אחד הכולל את כל ה-CSS, ה-JavaScript, הסקריפטים ומבנה ה-DOM.
   - כיווניות מלאה מימין לשמאל: `<html lang="he" dir="rtl">`.
2. **ספריות חיצוניות מאושרות (CDN):**
   - **Tailwind CSS:** `<script src="https://cdn.tailwindcss.com"></script>`
   - **גופן Rubik / Assistant:** מ-Google Fonts.
   - **FontAwesome 6:** אייקונים לכל הפעולות והחיוויים.
   - **Canvas Confetti:** לחגיגת סיום והצלחה (`confetti.browser.min.js`).
3. **זכויות יוצרים (Footer):**
   בתחתית הדף תוצג שורת קרדיט קבועה:
   `© כל הזכויות שמורות - נטלי דוד`

## 2. שער כניסה חובה לתלמיד ושמירה אוטומטית מלאה

### שער הכניסה (Student Gatekeeper)
- עם פתיחת הקובץ בדפדפן, כל לשוניות המשימות והתוכן הלימודי מוסתרים לחלוטין.
- מוצגת חלונית / מודאל נקי:
  - שדה **שם מלא** (חובה, `required`).
  - שדה **כיתה** (אופציונלי).
  - כפתור בולט: **"התחל בפעילות"** / **"כניסה לפעילות"**.
- רק לאחר לחיצה ותיקוף שהוזן שם תלמיד:
  - שער הכניסה נסגר / מוסתר.
  - נחשפים תפריטי המשימות ודף העבודה.
  - בראש המסך מוצג סרגל סטטוס אישי: "שלום, [שם התלמיד] | כיתה: [כיתה]".

### שמירה אוטומטית שקטה (ללא כפתור הגשה למורה!)
- **איסור מוחלט על כפתורי "שלח למורה", "הגש שיעורי בית" או "שלח מטלה".**
- במקום כפתור הגשה, מוצג תג סטטוס שקט ונעים בפינת המסך:
  - מצב רגיל: `🟢 שמירה אוטומטית פעילה`
  - בזמן שליחה: `🔄 שומר נתונים בשיטס...`
  - לאחר הצלחה: `✅ נשמר אוטומטית בשיטס` (חוזר למצב רגיל לאחר 3 שניות).
- **טריגרים לשמירה אוטומטית:**
  1. מיד עם כניסת התלמיד דרך שער הכניסה (רישום שורת נוכחות ראשונית).
  2. בכל פעולה אינטראקטיבית: שחרור גרירה בסלוט, בחירת תשובה ברב-ברירה, סיום הקלדה בשדה טקסט (`blur` / `change`), מציאת זוג במשחק זיכרון, או לחיצה על "בדוק תשובות".
- **עדכון אותה השורה:**
  כל עדכון שולח את מזהה הסשן הזמני (`sessionId` שנוצר בעת כניסת התלמיד) ואת שם התלמיד, כך שקוד ה-Apps Script מעדכן את **אותה השורה בגיליון** במקום לפתוח שורות חדשות.

## 3. ממשק "מנהלת השיעור" למורה

בראש הדף (בצד ימין עליון) מופיע כפתור קבוע:
`[ <i class="fa-solid fa-chalkboard-user"></i> מנהלת השיעור ⚪/🟢 ]`

### אבטחה וכניסה:
- לחיצה על הכפתור פותחת מודאל כניסה.
- סיסמת הגישה הקבועה: **`נטלידוד1234`** (ללא רווחים).
- שגיאה בסיסמה מציגה הודעה אדומה עדינה.
- הצלחה פותחת את לוח הבקרה של המורה (Teacher Dashboard).

### תוכן לוח הבקרה:
1. **שדה הגדרת ה-Google Sheets:**
   - שדה קלט לכתובת ה-Web App של המורה (`script.google.com/macros/s/.../exec`).
   - כפתור **"שמור חיבור"** (שומר ב-`localStorage` תחת מפתח ייעודי).
   - כפתור **"נתק או החלף מורה"** (מוחק את החיבור ומאפס את הטבלה המקומית).
2. **מדריכון מובנה צעד-אחר-צעד בעברית:**
   - הסבר ברור איך לפתוח Google Sheets חדש (`sheets.new`).
   - איך להיכנס לתפריט "הרחבות" -> "Apps Script".
   - כפתור **"העתק קוד Apps Script ללוח"** בלחיצה אחת.
   - איך לבצע פריסה חדשה (Deploy -> New Deployment -> Web App -> Anyone).
   - איך להעתיק את ה-Web App URL ולהדביק אותו בשדה החיבור.
3. **קוד ה-Google Apps Script המובנה:**
   מוגדר בתוך הסקיל ב-[apps-script-template.gs](./resources/apps-script-template.gs).
4. **טבלת מעקב חי (Live Data Table):**
   מציגה למורה את שמות התלמידים שנכנסו, השעה, הציונים בכל חלק, והתשובות שניתנו.

## 4. הפרדת נתונים מלאה בין מורות

- הנתונים משויכים אך ורק ל-URL הספציפי שהמורה הזינה.
- גיבוי מקומי ב-`localStorage` מתבצע תחת מפתח מבודד (למשל `teacher_data_` + גיבוב/קידוד של ה-URL).
- אם מורה חדשה פותחת את הדף וטרם חיברה גיליון, מוצגת הודעה:
  `"יש לחבר קישור גוגל שיטס אישי כדי לקבל ולראות את תשובות התלמידים שלך"`.
- לחיצה על "נתק או החלף מורה" מאפסת מיידית את התצוגה המקומית ומחזירה למצב התחלתי נקי.

## 5. הפקת קובץ וקישור נקיים לתלמידים

בפאנל המורה מוצגים 3 כפתורי פעולה:

1. **`שלח שורת בדיקה לשיטס שלי`:** שולח שורת בדיקה פיקטיבית לגיליון לווידוא תקינות ההרשאות.
2. **`העתק קישור מותאם לתלמידים שלי`:** מעתיק קישור עם פרמטר (למשל `?mode=student`) שמסתיר את כפתור מנהלת השיעור.
3. **`הורד קובץ מוכן לתלמידים שלי (ללא ממשק מורה)`:**
   - לוקח את ה-DOM הנוכחי.
   - **מסיר לחלוטין מהקוד ומגוף ה-HTML** את כפתור "מנהלת השיעור", את חלונית הסיסמה, ואת כל לוח הבקרה של המורה.
   - שותל בתוך הקוד את ה-URL של המורה כמשתנה מובנה קבוע (`let DEFAULT_EMBEDDED_SHEETS_URL = "https://...";`).
   - מאפס את שדות שם התלמיד והכיתה כך ששער הכניסה ייפתח נקי לתלמיד.
   - מוריד למחשב קובץ `.html` עצמאי ומוכן לשיתוף.

## 6. כללי ברזל (Iron Rules & Gotchas)

1. **בקובץ שיורד לתלמידים, אלמנטי המורה לא קיימים כלל ב-DOM** (לא רק `display: none`, אלא הוסרו פיזית).
2. **אין שמירה אוטומטית לפני כניסה בשער:** לא נשלחת אף קריאת רשת לשיטס לפני שהתלמיד הקליד שם ולחץ "התחל".
3. **ללא Alert מעיק:** הודעות למשתמש ולמורה מוצגות באמצעות Toast מעוצב ויפה.
4. **עמידות בניתוקי רשת:** אם קריאת הרשת לשיטס נכשלה, המערכת מציגה חיווי שקט `נשמר מקומית (ממתין לרשת)` ושומרת ב-`localStorage` עד לחידוש החיבור.
