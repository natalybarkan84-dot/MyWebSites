# תכנית לימודי לשון - כיתה ח' (בי"ס שקד)

חלוקת נושאי הלשון והדקדוק לאורך שנת הלימודים:

| חודש / תקופה | נושא לשוני מרכזי | מיומנויות נלוות |
|---|---|---|
| **ספטמבר - תשרי** | חזרה על חלקי דיבר (שם עצם, פועל, שם תואר), זכר/נקבה, יחיד/רבים | מילון ואוצר מילים, סדר א'-ב' |
| **חשוון - כסלו** | מילות קישור: הוספה (וגם, בנוסף), ניגוד (אבל, אך, אולם), סיבה ותוצאה (מפני ש-, מכיוון ש-, לכן) | חיבור משפטים, הבנת יחסי היגיון בפסקה |
| **טבת - שבט** | מערכת הפועל: זיהוי שורש, זמנים (עבר, הווה, עתיד, ציווי), התאמת גוף לפועל | שינוי זמן בטקסט, דיוק בהטיה |
| **אדר - ניסן** | בניינים קלים (פעל, פיעל, הפעיל), משמעויות הבניינים | יצירת מילים חדשות, משפחות מילים |
| **אייר - סיוון** | מבנה המשפט: משפט פשוט (נושא ונשוא), מילות שאלה, סימני פיסוק | כתיבת פסקת טיעון, עריכה לשונית |
