# תבנית פרומפט מחייבת ליצירת דף עבודה אינטראקטיבי ב-Gemini Canvas
(מותאם לרמת פרח - כיתת אלה, בית ספר שקד)

השתמש בתבנית זו בכל פעם שמתבקש פרומפט לדף עבודה אינטראקטיבי ב-Gemini Canvas (או כקובץ HTML עצמאי):

```markdown
בנה לי קובץ HTML מלא, עצמאי, יפהפה ואינטראקטיבי המותאם לתלמידי חינוך מיוחד (ASD) כיתה ח' (רמת פרח).

### הנחיות טכנולוגיות ועיצוביות:
1. **קובץ יחיד:** כל ה-HTML, CSS ו-JavaScript בקובץ אחד. כיווניות מימין לשמאל: `<html lang="he" dir="rtl">`.
2. **ספריות עיצוב:** Tailwind CSS, גופן 'Rubik' מ-Google Fonts, סמלי FontAwesome 6, וספריית Canvas Confetti להצלחות.
3. **סרגל עליון:** כפתור "מנהלת השיעור" (סיסמה: `נטלידוד1234`), חיווי שמירה אוטומטית שקט, שער כניסה לתלמיד עם שם מלא.
4. **זכויות יוצרים בתחתית הדף:** `כל הזכויות שמורות - נטלי דוד`.

### התאמות ייחודיות לרמת פרח:
- **כפתור הצג/הסתר ניקוד:** מתג בראש הדף המאפשר לתלמיד להציג או להסתיר את סימני הניקוד בטקסט (קריטי עבור ירדן שמעדיף ללא ניקוד, מול עידו שזקוק לניקוד מלא).
- **תמיכה דו-לשונית לירדן (Bilingual Scaffolding):** ליד מונחים והוראות מרכזיות יש לצרף תרגום קצר לאנגלית בסוגריים עדינים, למשל: `מילות קישור (Linking Words)`.
- **כפתור הקלטה קולית לתלמיד:** מאפשר לתלמיד להקליט את תשובתו בעל-פה (באמצעות Web Audio / MediaRecorder) כדי לעקוף קשיי הקלדה.

### כללי הקראה קולית מחייבים (TTS Audio Rules):
- **חל איסור מוחלט על שימוש ב-`window.speechSynthesis`** עקב חוסר תמיכה אמינה בעברית מנוקדת.
- **ההקראה תתבצע אך ורק באמצעות `new Audio()` ו-Google Translate TTS**:
  כתובת ה-URL לשליחה:
  `https://translate.google.com/translate_tts?ie=UTF-8&tl=he&client=tw-ob&q=` + encodeURIComponent(vocalizedWord)
- כל מילה הנשלחת להקראה חייבת לכלול **ניקוד עברי מלא ומדויק** בתוך ה-URL להגייה נכונה של קריין/קריינית.
- בכל מקום שבו מוצגת שאלה, טקסט או כרטיסייה יש להציב כפתור רמקול קטן `🔊` בלחיצה.
- טיפול בשגיאות רשת יתבצע באופן שקט באמצעות `.catch()` ללא הודעות `alert()`.

### מבנה התוכן הלימודי בדף:
1. **שער כניסה לתלמיד:** הזנת שם מלא, פתיחת דף העבודה רק לאחר הזנה.
2. **קטע קריאה מותאם:** מחולק לפסקאות קצרות, עם כפתור הקראה לכל פסקה ומתג ניקוד.
3. **10 שאלות אינטראקטיביות מדורגות:**
   - שאלות איתור מידע (רב-ברירה עם משוב מיידי וצבעוני).
   - שאלות השלמת משפטים בגרירה (Drag & Drop) עם סלוטים מעוצבים.
   - שאלות נכון / לא נכון עם אייקונים.
   - שאלת התאמת מושג להגדרה.
4. **משחק זיכרון מסכם:** כרטיסיות מתהפכות (מושג מול הגדרה או מילה מול פירושה) עם מונה צעדים וקונפטי בסיום.
```
